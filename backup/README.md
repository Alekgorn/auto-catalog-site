# Страховочная копия сайта

Здесь лежит всё, что нужно, чтобы поднять сайт заново на своём сервере —
даже если доступа к платформе больше не будет.

**Копия обновлена: 10 сентября 2026.**

## Что в папке

| Файл | Что это | Размер |
|---|---|---|
| `database.sql` | Все данные: 1818 товаров, 66 марок, 14 категорий, 1387 связок проводки, 5 статей, 2 инструкции, настройки | 2,5 МБ |
| `images-list.txt` | Адреса всех 1923 фотографий сайта | 232 КБ |
| `download-photos.sh` | Скачивает фотографии по этому списку | — |
| `РАЗВОРАЧИВАНИЕ.md` | **Подробная инструкция: как поднять сайт с нуля** | — |

Сам код сайта лежит в этом же репозитории, папками выше.
Структура базы (какие таблицы и поля) — в папке `db_migrations`.

## С чего начать

Откройте **`РАЗВОРАЧИВАНИЕ.md`** — там пошаговый порядок действий,
требования к хостингу, примеры настройки сервера и разбор частых
ошибок.

Кратко:

```bash
# 1. База: сначала структура, потом данные
createdb shtatno
cd db_migrations && for f in V*.sql; do psql -d shtatno -f "$f"; done
psql -d shtatno -f backup/database.sql

# 2. Фотографии
sh backup/download-photos.sh ./photos

# 3. Сайт
npm install && npm run build && node scripts/prerender.mjs
```

## Что изменилось с прошлой копии

Прошлая копия (26 августа) качала фотографии одним архивом, который
лежал на хранилище платформы. Это было слабое место: пропадёт доступ
к платформе — и качать станет неоткуда, ровно в тот момент, когда
копия нужна. Теперь фотографии скачиваются по списку адресов.

Заодно пересчитаны данные: товаров стало 1818 вместо 1441.

## Рядом есть вторая папка — `backups`

Не пугайтесь двух папок, они про разное:

- **`backup`** (эта) — готовый набор для переезда: SQL-файл, который
  заливается одной командой, и пошаговая инструкция.
- **`backups`** — снимки данных на дату в виде JSON, включая заказы
  и дилеров. Оттуда удобно достать что-то точечно, но развернуть
  сайт одной командой не выйдет.

Для восстановления сайта берите эту папку. За старыми заказами —
в соседнюю.

## Чего в копии нет

**Заказов покупателей и данных дилеров.** Это персональные данные,
их не хранят в репозитории — туда есть доступ у всех, у кого есть
доступ к коду. Понадобятся при переезде — выгрузите отдельно из
админки либо возьмите из соседней папки `backups`, где сохранён
снимок на 4 сентября.

**Паролей и ключей доступа.** Никогда не попадают в репозиторий.
Задаются на сервере отдельно, список нужных — в инструкции.

**Сессий входа и кеша поиска.** Временные данные, создаются заново
сами.

## Про 23 чужие фотографии

В каталоге 1923 фотографии, из них 1900 лежат на нашем хранилище,
а 23 — на сайте поставщика (`images-ru.ksize.ru`). Эти могут пропасть
в любой момент, и мы на это не влияем.

Стоит перенести их к себе заранее: в админке раздел
**Сайт → Настройки → Перенести фото к нам**.

## Важно

Копия отражает состояние на дату создания. Правки товаров через
админку в неё не попадают автоматически — обновляйте хотя бы раз
в месяц. Устаревшая страховка — это не страховка.
