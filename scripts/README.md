# Предрендер страниц

Сайт — одностраничное приложение: поисковые боты видят пустую страницу
и ждут выполнения скриптов. Предрендер решает это — заранее собирает
готовый HTML каждой страницы, чтобы бот получил текст сразу.

## Как обновить страницы

Запускать нужно после того, как в админке поменялись товары или инструкции:

```bash
npx vite build                                    # обычная сборка — даёт шаблон
npx vite build --config vite.prerender.config.ts  # серверная сборка
node scripts/prerender.mjs                        # генерация страниц
```

## Что получается

- `index.html` — главная с готовой разметкой и данными каталога внутри
- `public/product/<код>/index.html` — страница каждого товара
- `public/guides/index.html` и `public/guides/<код>/index.html` — инструкции
- `public/sitemap.xml` — карта сайта со всеми адресами

Файлы из `public/` попадают в сборку как есть и отдаются как обычная статика.

## Как это устроено

- `src/entry-prerender.tsx` — точка входа для рендера вне браузера
- `src/lib/seo.ts` — мета-теги: в браузере ставит в `<head>`, при сборке
  складывает в память, откуда их забирает генератор
- `window.__CATALOG__` — данные каталога, вшитые в HTML, чтобы первый экран
  не ждал ответа сервера

Повторные запуски безопасны: генератор сначала очищает прошлую разметку,
файл не растёт.
