Описание

Всё о товаре

Назначение Адаптер 3.5 мм → 20-pin для подключения внешнего микрофона к Android-магнитоле через 20-пиновый RCA-разъём. Улучшает качество голосовой связи (Bluetooth-звонки) и голосового управления в автомобиле.

Важные уточнения Подходит только для Android-магнитол (не для штатных автосистем). Требует наличия 20-pin RCA-разъёма на магнитоле.

Комплектация
  • Кабель микрофона для установки в 20 ти пиновый разьем Андроид магнитолы
