# Резервные копии

Здесь лежат снимки данных сайта на конкретную дату. Файлы уезжают в
репозиторий вместе с кодом — значит копия хранится там же, где история
изменений, и не пропадёт вместе с сервером.

## Что в папке

**`catalog-ГГГГ-ММ-ДД.json`** — данные сайта.

| Таблица | Что это |
|---|---|
| `products` | товары со всеми полями: цены, фото, совместимость, признаки подключения |
| `brands` | марки, модели и кузова моделей |
| `vehicle_wiring` | разметка подбора по машинам: периоды, кузова, сторона руля |
| `settings` | настройки сайта: контакты, справочник признаков, блоки фильтров |
| `categories`, `category_specs` | разделы каталога и их характеристики |
| `guides`, `product_guides` | инструкции и привязка к товарам |
| `dealers` | дилеры с доступом к оптовым ценам |
| `missing_fit_requests` | заявки «моей машины нет в списке» |
| `orders` | заказы |

Не сохраняются: сессии администратора, кэш поиска, журнал неудачных
загрузок фото, служебные таблицы хранилища. Всё это создаётся заново
само и восстановления не требует.

**`photos-ГГГГ-ММ-ДД.json`** — опись фотографий: адрес каждого файла и
товар, которому он принадлежит. Сами снимки лежат в хранилище S3 с
раздачей через CDN, в репозиторий их не кладём — это гигабайты, и Git
для двоичных файлов такого объёма не предназначен. По описи видно, что
есть, и любой файл скачивается по адресу.

## Зачем опись, если есть само хранилище

Хранилище отвечает на вопрос «какие файлы лежат», опись — на вопрос
«какие файлы нужны». Если снимок пропал, по описи видно, к какому товару
он относился и какой по счёту был в карточке. Без неё пришлось бы
сверять тринадцать тысяч адресов вручную.

## Как восстановить

Раздел «Настройки» в админке умеет загружать каталог из файла. Для
полного возврата данных отдайте `catalog-*.json` разработчику: часть
таблиц (дилеры, заявки, привязка инструкций) через интерфейс не
заливается.

## Как часто обновлять

Перед крупными правками каталога и после больших загрузок прайса. Старые
копии удалять не нужно — файл сжимается в репозитории, а возможность
вернуться на месяц назад однажды окажется дороже места на диске.
